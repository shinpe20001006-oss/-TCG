# 組み立てTCG オンライン版

ブラウザで遊べる対人戦つきの組み立てTCG。サーバーは Node.js(Express + ws)、保存は PostgreSQL(Neon)。

## しくみ
- **対戦**: 両者のブラウザが同じ乱数シードで同じゲームエンジンを動かし、操作(カードを出す・攻撃など)だけをサーバー経由で送り合います(サーバーは中継のみ)。毎ターン、盤面のハッシュを照合して食い違いを検出します。
- **データ保護**(デッキ・所持カード): サーバー側のPostgreSQLに保存します。Renderの無料プランはファイルが再起動・更新で消えるため、**必ず外部DB(Neon)を使います**。DBのテーブルは「追加のみ」のマイグレーション(`lib/store.js`)で更新するので、コードを更新してもデータは消えません。`NODE_ENV=production` で `DATABASE_URL` が無いと、データ保護のため起動を拒否します。
- **ログイン**: 端末ごとに自動でIDとトークンを作成し(ブラウザのlocalStorage)、初回に**引き継ぎコード**(XXXX-XXXX-XXXX)を表示します。別の端末ではタイトル画面の「アカウント」からコードを入力すると、デッキと所持カードを引き継げます。
- **ガチャ・所持カード**: サーバー判定にする前提で、所持カード(`inventory`)はサーバー側のテーブルで管理しています。いまは全カードを配布済み(基本カード)。デッキは所持枚数を超えて保存できません(サーバーも検証)。

## デプロイ手順(GitHub + Render + Neon)
1. **Neon**(https://neon.tech)でプロジェクトを作り、接続文字列(`postgresql://...`)をコピー。
2. このフォルダを GitHub のリポジトリに push。
3. **Render** で `New > Blueprint` → そのリポジトリを選ぶ(`render.yaml` が読まれます)。
4. 環境変数 `DATABASE_URL` に Neon の接続文字列を貼って保存 → デプロイ。
5. 表示されたURLを開き、タイトル画面の「対人戦」→「ルームを作る」。表示された5文字のコードを相手に伝えます。

Renderの無料プランは15分アクセスが無いと眠り、次のアクセスで起動に約1分かかります。対戦中の接続は保たれますが、サーバーが再起動するとその対戦は終了します(データは残ります)。

## ローカルで動かす
```
npm install
npm start          # http://localhost:3000 (DATABASE_URL が無いと一時メモリDB。再起動で消えます)
npm test           # API・アカウント引き継ぎ・2クライアントの同期対戦テスト
```

## カードを増やしたとき
`public/index.html` を更新したら `node gen-catalog.js` で `lib/catalog.json` を作り直します(所持枚数・デッキ検証の元データ)。基本カードとして全員に配るなら `lib/store.js` の `STARTER_VER` を1上げます(足りない分だけ配られ、既存の所持数は減りません)。
